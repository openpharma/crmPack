# Add the Next-Best Dose Marker

Add the Next-Best Dose Marker

## Usage

``` r
h_next_best_marker(plot, dose, y, dose_grid, dose_scale)
```

## Arguments

- plot:

  (`ggplot`) plot to decorate.

- dose:

  (`number`) next best dose.

- y:

  (`number`) vertical marker position.

- dose_grid:

  (`numeric`) ordered dose grid.

- dose_scale:

  (`string`) dose-axis scale.

## Value

The decorated `ggplot2` object.
